# 01_F1 — 環境還原的反例與負向控制

| Field | Value |
| --- | --- |
| Flow | F1 環境還原（`REQ-F-F1-1`） |
| Model | `tests/testthat/test-01_F1.R`、`tests/testthat/harness-01.R` |
| Seed | `n/a`（本流程無隨機來源；測試台的 `HARNESS_SEED = 20261117` 只記錄，不驅動行為） |
| Shrink | `n/a`（同上；收縮上界 200 次／30 秒未用） |
| Budget | 樣本 0 資料列；三次子程序執行（專案根 1、副本還原 1、副本重跑 1、副本拒絕 1）；單流程上限 600 秒，實測約 17 秒 |

反例一律記成三項：**trace**（哪一條斷言、哪一行）、**最短序列**（能重現的最小步驟、
可直接貼上的指令）、**紅燈輸出**（判紅時實際印出的字）。

## NC-1 · 釘值改錯一位：P1 必須轉紅

**trace**：`test-01_F1.R:39`，`expect_identical(values, unname(F1_PINNED))`。

**最短序列**（在 owned 測試檔內改一個字，其餘不動）：

```
sed -i '' 's/values, unname(F1_PINNED),/values, c(3631L, 2828L),/' tests/testthat/test-01_F1.R
Rscript tests/testthat.R
```

**紅燈輸出**（實跑）：

```
01_F1: ...1........................................
── 1. Failure ('test-01_F1.R:39:3'): F1-P1 專案根目錄的具名指令成功結束，兩個母體常數為正整數
Expected 常數等於釘值 3630 / 2828 to be identical to `c(3631L, 2828L)`.
Differences:
1/2 mismatches
[1] 3630 - 3631 == -1
Error: ! Test failures. 停止執行   (exit 1)
```

**判定**：斷言讀的是子程序真的印出的兩個數，不是斷言裡的字面值；改一個字就紅，改回來就綠
（`diff` 對原檔為 empty）。這是「被改錯的斷言」那一條負向控制。

---

## NC-2 · 記錄缺一欄：P4 的「三欄齊備」轉假

**trace**：`test-01_F1.R` 的 `for (key in F1_LOG_FIELDS) expect_false(f1_log_fields_complete(f1_drop_field(section, key)))`。

**最短序列**：對一次真實還原寫出的 `00_setup.log` 段落，刪掉
`r_version:`／`package_count:`／`restore_elapsed_sec:` 任一行，再問同一條判定。

```
section <- f1_sections(f1_read_log(<那次執行的輸出根>))[[1]]
f1_log_fields_complete(f1_drop_field(section, "package_count"))   # FALSE
```

**紅燈輸出**：三欄各一次，皆 `FALSE`（實測）。欄位刪掉後段落仍可解析，故這條判紅的
原因是「缺欄」，不是「段落壞掉」。

**判定**：`expect_false()` 三道，缺任一欄都紅——三欄不是一個布林的別名。

---

## NC-3 · 欄在而值是空的：弱斷言會放過，形狀斷言不會

**trace**：`test-01_F1.R` 的 `expect_false(f1_log_fields_shaped(blanked))`。

**最短序列**：把 `restore_elapsed_sec: 6.8` 改成 `restore_elapsed_sec: `（只刪值、留欄名）。

```
blanked <- f1_mask(section, "^restore_elapsed_sec: .*$", "restore_elapsed_sec: ")
any(grepl("^restore_elapsed_sec:", blanked))   # TRUE ← 弱斷言看到這裡就放行
f1_log_fields_shaped(blanked)                  # FALSE
```

**反例的形狀**：`grep "restore_elapsed_sec"` 這種只問欄名在不在的寫法，對上列記錄**判綠**。
本模型因此把「在不在」與「值對不對」拆成兩個判定（`f1_log_fields_complete()` 與
`f1_log_fields_shaped()`），並保留一行 `expect_true(any(grepl("^restore_elapsed_sec:", blanked)))`
把「這個反例確實只刪值」釘住——否則日後有人改了遮罩、負向控制會悄悄變成恆真。

## NC-4 · 拒絕清單沒指名：P3 的「寫明缺哪一個」轉假

**trace**：`test-01_F1.R` 的 `expect_false(any(grepl("PropCIs", f1_mask(bullets, "PropCIs"), fixed = TRUE)))`。

**最短序列**：

```
copy <- f1_copy(drop = "PropCIs")     # 副本的 renv.lock 少了 PropCIs
run <- f1_run(copy$dir)               # exit 1，類別 refuse:unpinned-package
masked <- f1_mask(f1_bullets(f1_sections(f1_read_log(run$out_root))[[1]]), "PropCIs")
any(grepl("PropCIs", masked, fixed = TRUE))   # FALSE
```

**判定**：清單的名字被遮掉後同一條斷言轉假，故「寫明缺哪一個」不是靠
`refuse:unpinned-package` 這個類別字串在撐——類別與名目是兩個獨立的判定。

## CE-1 · 真正抓到的一個反例：子程序繼承了 session 的 renv 身分

這是本流程第一個實作版本的真實失敗，也是本模型唯一一條**非注入**的反例；它留在這裡
是因為任何後續的 harness 都會踩到同一件事。

**trace**：`F1-P2` 的 `expect_identical(probe$run$status, 0L)`；實得 1，記錄 0 段。

**紅燈輸出**（副本子程序的合併輸出）：

```
[.Rprofile] 版本環境缺件，執行 renv::restore()
錯誤: refuse:unpinned-package — 還原後仍未滿足鎖定檔：
  PropCIs, R6, backports, bit, ..., vroom, waldo, withr          （52 個全列）
停止執行
```

**最短序列**：

```
# 在一個「已是 renv session」的父程序裡（例如 Rscript tests/testthat.R）
copy <- f1_copy(); f1_run(copy$dir)     # 還原什麼都沒裝 → 守衛在差額檢查停下
```

**機制**：父 session 把 `RENV_PROJECT` 與 `R_LIBS_USER` 指向真實樹的 library。子程序
繼承後，renv 把「專案」解讀成真實樹：還原裝進真實樹（已滿足，於是一個都不裝），
副本的 `renv/library` 仍是空的，守衛在還原後的差額檢查以 `refuse:unpinned-package`
停下。第二種繼承組合更糟：renv 失去套件快取，改從原始碼編譯 52 個套件（實測逾 400 秒，
單流程上限 600 秒會被吃光）。

**修法與釘子**：`f1_env()` 以 `env -i` 起子程序，只帶 `HOME`／`PATH`／`TMPDIR`／`LANG`
四個與專案無關的變數，`RTOOLKIT_*` 一律給空值。修後同一個副本 6.0 秒還原完、
52 個套件全部 `linked from cache`。這條反例說明 F1 的「新機器」語意必須由 harness
顯式造出來，不能靠「反正子程序會繼承」。

---

## 沒抓到的，與為什麼

- **鎖定檔改新（只補差額）**：`00_setup.log` 的 `added_on_restore` 只在真跑過
  `renv::restore()` 時才有值（`RTOOLKIT_RESTORE_ACTION=restore`）。造這個反例需要一個
  比現行鎖定檔舊的 library，成本是一整套降級安裝；記在此處不進測試，屬 T01 的
  `Boundary behaviour`，本流程只判定「無操作重跑」與「缺件還原」兩支。
- **來源不可達**：PRD 的拒絕路徑含「套件來源不可達」，但要在測試內斷網或改 repos；
  拒絕類別與 `refuse:unpinned-package` 相同，P3 已覆蓋同一支的停止與記錄行為。
