## 2. 釘值（表內實測，四位有效數字）

| cell | 標籤 | n | 退學人數 | dropout_rate | share |

| `w_only_debt` | 僅欠債 | 187 | 97 | 0.5187 | 0.05152 |

- `dropout_rate` 的分母是**該格人數**：`226 × 0.9513274… = 215`。以分析母體為分母的版本
  會得 0.0592，與釘值在四位有效數字上不同（測試以 `expect_false()` 把這條寫成反面錨）。
- 四格率**不得**相加成 100%：未加權的和為 2.694；以 share 加權的和才是全體退學率 0.3915。
- `phi = 0.43490550483822404`（四位有效數字 0.4349，容差 1e-3），四列同值。

## 3. phi 的符號與置換表（2×2 為 [226 260; 187 2957]）

| 操作 | phi | 四位 | 與基準的關係 |
| --- | --- | --- | --- |
| 基準（欠繳=1、欠債=1） | 0.4349055048 | 0.4349 | — |
| 整列互換（列 1 ↔ 列 2） | −0.4349055048 | −0.4349 | 變號、絕對值不變 |
| 整欄互換（欄 1 ↔ 欄 2） | −0.4349055048 | −0.4349 | 變號、絕對值不變 |
| 對角互換（轉置，b ↔ c） | 0.4349055048 | 0.4349 | 不變 |
| 單格對調（a ↔ b） | 0.4927638105 | 0.4928 | **不變號** → A-10 駁回的舊斷言 |
| 編碼反轉（繳清=1、欠債=1） | −0.4349055048 | −0.4349 | 變號：符號來自編碼，不是資料 |

單格對調那一列是本檔的「斷言不是恆真」證明：`expect_false(f3_sig_equal(f3_phi(260,226,187,2957), -phi))`
必須成立，否則「整列互換變號」這條就退化成任何置換都成立的空話。

## 5. 反例與「最短序列」

| 反例 | 最短序列（單一突變） | 觀察 |
| --- | --- | --- |
| 空格・整列 | `frame$Debtor <- 0` → 寫成清洗形狀 → `RTOOLKIT_CLEAN_PATH` | `refuse:empty-denominator`；`w_both`、`w_only_debt` 為空；表未覆寫 |
| 空格・整欄 | `frame[["Tuition fees up to date"]] <- 1` → 同上 | `refuse:empty-denominator`；`w_both`、`w_only_unpaid` 為空；不寫表 |
| 舊列序（A-22 之前） | 表內 n 與 `c(260, 226, 187, 2957)` 比較 | 紅：226 − 260 = −34（見第 6 節 A 以外之 B） |
| 編碼反轉 | 期望 `−0.4349` | 紅：`"0.4349"` ≠ `"-0.4349"` |

**收縮**：本流程沒有隨機來源，失敗輸入的空間是「四格 × 兩欄」的邊界，只有兩個突變運算子
（`Debtor <- 0`、`Tuition <- 1`）；兩者皆已枚舉並固定，故隨機最小化無事可做，收縮步數記 0、
最短序列即上表的單一突變。**種子** n/a 同理。

## 6. 負向控制（被改錯的斷言必須紅）

在 `harness_dir()` 級別的暫存副本上（`helper-harness.R`、`harness-03.R` 與四份變異測試各一份，
以 `AMS2640.Rproj` 標記與 symlink 自成專案根）逐份執行 `testthat::test_dir()`；真實樹的
`tests/testthat` 不動。四份變異各只紅一條，且紅的就是被改的那條：

| 變異 | 改錯的斷言 | 紅燈輸出（節錄） |
| --- | --- | --- |
| A | phi 釘值寫成 `−0.4349`（把編碼讀成繳清=1） | `Expected 四位有效數字後為 −0.4349 ... to be identical to f3_sig(-F3_PIN_PHI)` / `x[1]: "0.4349"` `y[1]: "-0.4349"`；`failed=1` |
| B | 逐格 n 依 A-22 之前的舊序（僅欠繳在第一列） | `2/4 mismatches (average diff: 34)` / `[1] 226 - 260 == -34`；`failed=1` |
| C | 空格分支改成「不得拒絕」（status 期望 0） | `Expected 刻意改錯：假設空格不拒絕 to equal 0L` / `[1] 1 - 0 == 1`；`failed=1` |
| D | sha256 斷言反向（要求拒絕後表已變） | `Expected 刻意改錯：要求拒絕後表已變 to be FALSE` / `actual: TRUE`；`failed=1` |

同一批斷言在真實樹上全綠（61 條期望、0 失敗、0 警告、結束碼 0）——四份變異證明它們不是恆真。
