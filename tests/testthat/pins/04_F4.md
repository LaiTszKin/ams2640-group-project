## 3. 負向控制一（模型性質）：單身改取 1

同一支副本只換 `single <- … %in% SINGLE_VALUES` 為 `== SINGLE_VALUES[1L]`：

| 帶 | 已婚／單身 | 四格（已婚退學／已婚畢業／單身退學／單身畢業） | p | `status` |
| --- | --- | --- | --- | --- |
| 30–39 | 153／207 | 87／66／150／57 | **0.002399785918** → 0.0024 | `ok` |
| 40+ | 115／63 | 61／54／43／20 | 未過門檻的雙尾值 **0.05705992356** | **`insufficient_n`** |

- 30–39 的 p 由 0.02455 變 0.0024，證明釘值由「已婚 = 2、單身 = 其餘」這個讀法承載。
- 40+ 在 `單身 = 1` 下單身組只剩 63 人、最小格 20 < 30，故**分支②先於③**：入表、`p_value` 留空、
  標 `insufficient_n`。契約所記的 0.0571（四位有效數字為 0.05706）是**未經門檻**的 Fisher p，
  生產程式在此輸入下不會輸出它——測試兩者都釘（表內 `status` 與自算的未過門檻 p）。

## 6. 載入路徑熱修（讓 `test_dir()` 單獨呼叫也全綠）

**症狀**（主代理實測）：在 worktree 內跑 `Rscript -e 'testthat::test_dir("tests/testthat", reporter="summary")'`，
三條 error 全在 `test-04_F4.R`，訊息皆為「沒有這個函式」：

```
1. Error ('test-04_F4.R:158:3'): Error in `harness_data("analysis")`: 沒有這個函式 "harness_data"
2. Error ('test-04_F4.R:172:3'): Error in `harness_dir()`: 沒有這個函式 "harness_dir"
3. Error ('test-04_F4.R:202:3'): Error in `harness_out_root()`: 沒有這個函式 "harness_out_root"
```

**根因**：R 的函式以**定義時的 enclosure** 解析自由變數，不是呼叫端。`harness-04.R` 被
`test-04_F4.R` `source()` 進 globalenv，故 `h04_*` 的 enclosure 是 globalenv；而 `test_dir()`
把 `helper-harness.R` 載進**它自己的測試環境**（不是 globalenv）。`Rscript tests/testthat.R`
之所以綠，只因入口先 `source()` 了 helper 進 globalenv——即 §1 的綠燈是入口的副作用，
不是本檔的性質。（同一段程式碼在測試檔**本體**內呼叫 `harness_data()` 沒事：那是呼叫端
環境鏈；出事的只有包在 `h04_*` 裡的呼叫。）

**修法**：`harness-04.R` 新增 §0，在**載入時**把 helper 載進「本檔自己的求值環境」
（top level 的 `environment()`，即 `source(local=)` 的目標），落點與 `h04_*` 的 enclosure
相同，故不需要任何先載入動作。目錄以 `--file=` → source frame 的 `ofile` → 工作目錄
（含 `tests/testthat`）三段解析；載入後逐一點名 `harness_data`／`harness_dir`／
`harness_out_root`／`harness_table`，缺一即停止（「以為載入了」比沒載入更難查）。
`test-04_F4.R` 的載入段改為 `source(..., local = FALSE)` 並寫明落點是 globalenv。
