# 財富、社會背景與能力對畢業率的影響

以 UCI 學生退學／畢業資料，檢視財富背景、社會背景、能力三層與畢業的關係，並由此指出績優主義的客觀局限。

## 摘要

本報告整理一次為 AMS2640 課程報告作準備的討論。已確立的是三層的欄位、人口界線、能力的量度方式、四項判準、財務背景的兩段鏈條（父母職業 → 資助與繳費 → 畢業），以及文化資本的分解（父母學歷的總效應、經財務與不經財務兩部分）；未確立的是「主導」的比較結果與十頁篇幅的取捨。

## 主題與範圍

本報告處理一份葡萄牙高等院校的學生資料，共 4,424 筆、36 個變數。分析的對象是三類結果中的兩類——已畢業與已退學，共 3,630 人；仍在讀者另計 [Q18][Q24]。範圍的一端停在資料可量度的欄位，另一端停在「績優主義」這一評價性主張的入口。

範圍的三條邊界是因果推論、跨地區比較與篇幅。第一是因果推論：資料在一個時點上記錄社經背景，在兩個學期上記錄成績，退學的理由在紀錄中為空白 [Q25]。第二是跨地區的比較：宏觀三欄只有九至十個值 [Q37]。第三是篇幅：課程指引的十頁上限如何容納三層，見「尚未確立的」一節 [Q35]。

## 現在確立的

三層各有一組欄位，邊界以欄位劃定。社會背景七項：報名方式、國籍、父母學歷、婚姻狀況、離鄉就學、國際生、入學年齡 [Q14][Q15]。財富背景三項：父母職業、學費是否繳清、是否領獎學金 [Q14][Q39]。宏觀環境三項：失業率、通脹率、GDP [Q14]。能力一層以在校成績的分位分組，入學前的成績另計 [Q26]。

家境這一層的入口是「學費是否繳清」。四格退學率把欠繳與欠債分開計：兩者俱有 95.13%（226 人）、只有欠繳 93.08%（260 人）、只有欠債 51.87%（187 人）、兩者俱缺 29.32%（2,957 人）；兩個標記的 phi 為 0.4349 [Q29]。欠繳這一欄在時間上早於退學，理由是其屬 UCI 資料描述中「入學時已知」的社經欄位 [Q25][Q40]。

### 財務背景的兩段鏈條：職業、資助、繳費

父母的職業是收入背景唯一可用的代理，它對畢業率的直接關聯很弱。以七個實質職業階級（高層與專業、中層技術與行政、服務銷售與保安、農漁林、工業建築技工、機械操作與裝配、非技術）對畢業率作檢定，母親一側 χ² = 9.195（df = 6）、p = 0.1629；父親一側 χ² = 14.54、p = 0.02411。二十二個「單組對其餘」的精確檢定經 BH 校正後，只有父親的工業建築技工一組通過（67.26%，n = 562，p_bh = 0.00259），而該組的優勢在控制繳費之後消失（OR = 0.9963，p = 0.9746）。以職業直接預測畢業，測到的是收入的粗糙代理，不是收入本身 [D1]。

職業的位置在鏈條的上游，不與繳費並列為另一個入口。它對資助資格有清楚的梯度。學費繳清與否在職業階級之間幾乎沒有分別：母親一側的欠繳率由 6.494% 至 14.87%（χ² = 13.21、df = 6、p = 0.03980、η = 0.06233），父親一側由 10.32% 至 16.84%（p = 0.06519、η = 0.06082）。獎學金則拉開三倍半至四倍：高層與專業家庭 9.309%（母）／7.985%（父），非技術家庭 32.74%／33.91%，工業建築技工家庭 40.35%／39.15%；母親一側 χ² = 111.8、p = 8.681×10⁻²²、η = 0.1813，父親一側 χ² = 119.8、p = 1.821×10⁻²³、η = 0.1933 [D1]。

這裡有一個必須寫明的分別。繳費記錄與職業的關聯很弱（η 約 0.06），故它不宜當作收入水平的代理，它記錄的是財務衝擊的時點；收入水平由獎學金資格反映得更清楚。後一讀法立在一項未核實的前提上：獎學金在該校為須審查的資助。前提核實之前，這一段只能寫成假設 [D1]。

鏈條的下游一段是全份資料中最強的關聯。欠繳者畢業率 5.967%（486 人），未欠繳者 69.34%（3,144 人）；欠債者 24.46%（413 人），未欠債者 65.53%（3,217 人）；獎學金持有者 86.17%（969 人），未持有者 51.63%（2,661 人）。「欠繳 × 獎學金」四格把兩端拉開：欠繳且未受助 4.454%（449 人），未欠繳而受助 88.63%（932 人），跨度 84.18 個百分點 [D1]。

由此，財務背景的影響以三種形式出現，強度依序為：繳費與資助（四格跨度 84.18 個百分點）、家境四格（phi = 0.4349）、父母職業（總效應不顯著）。三者不是同一件事的三種說法，而是同一條路徑上三個位置的量度：職業在上游、繳費在中游、畢業在下游。把中游調掉再看上游，得到的是直接效應，不是總效應；以此宣稱收入背景不重要，等於把要看的路徑自己切斷 [D1]。

能力以第二學期成績的四分位分組。每組 707 人，母體 2,828；該期成績為 0 的 802 人由分組中剔除，其中 727 人為退學者。四分位的畢業率依序為 51.77%、76.94%、83.88%、89.25%。曲線按人追蹤，同一個人在兩期可以換組 [Q27][Q34]。

年齡與畢業率的關係呈非單調的形狀。各年齡帶的退學率依序為：20 歲以前 25.23%（1,621 人）、20–24 歲 36.88%（1,033 人）、25–29 歲 69.30%（355 人）、30–39 歲 64.02%（403 人）、40 歲以上 58.26%（218 人）。頂點落在 25–29 歲一段 [Q32]。

這一形狀由「收入穩定性 × 財富存量」解釋。40 歲以上收入相對穩定，30–39 歲收入波動較大，25–29 歲兩項俱缺。各帶的欠繳率依序為 6.720%、12.00%、27.89%、24.57%、25.23%；25–29 與 40+ 的欠繳率落在同一個區間（Fisher p = 0.4987），兩者的退學率則分離（p = 0.0088）[Q32][Q41]。

「主導」一詞在三條判準下使用：建模的解釋力、模型背後的宏觀邏輯、以及可否證偽 [Q38]。以邏輯迴歸量度，年齡帶單獨的 McFadden R² 為 0.07557，財務三欄為 0.2227（母體 2,828 上為 0.2011），第二學期成績分位為 0.09577（母體 2,828），入學成績分位為 0.004952（同一母體）[Q36][Q38]。

宏觀三欄以控制變數的身分進入模型。每位學生共用其入學年份的失業率、通脹率與 GDP，三欄各只有九至十個值 [Q37]。

### 社會背景之一：父母學歷與文化資本

文化資本在此只取制度化的一種形式：父母的最高學歷。三種形式的分別出自 Bourdieu，本節不使用語言與品味那兩種實踐形式，因為欄位裡沒有；文獻條目待補並核對版本。[D2]

假設的鏈有兩個箭頭，兩者都是假設：父母學歷 → 家庭的文化資源（對學校制度的熟悉、對升學的期望、可提供的學業支援）→ 畢業。資料只記錄兩端，中間那一段沒有量度。財務資本是這條鏈的競爭解釋，而它本身又是學歷的下游（學歷 → 收入 → 資助與繳費 → 畢業）；故學歷的效應須拆成「經財務標記」與「不經財務標記」兩部分，後者才屬於文化資本的獨立量。[D2]

分級依 UCI 697 的官方碼：高等教育（2–6、40、41、43、44）、技術高等教育（39、42）、中等教育完成（1、13、18、20、22、25、27、31、33）、中學以下（9–12、14、19、26、29、30、38）、小學或以下（35–37）、34 未填。未填碼不進整體檢定。[D2]

各級畢業率如下，括號內為人數與 95% 威爾遜區間。母親：高等教育 60.55%（469 人，56.06% 至 64.87%）、技術高等教育 40.00%（10 人）、中等教育完成 65.21%（868 人，61.98% 至 68.30%）、中學以下 66.03%（1,310 人，63.42% 至 68.54%）、小學或以下 54.26%（846 人，50.89% 至 57.59%）、未填 24.41%（127 人，17.76% 至 32.56%）。父親：55.45%（321 人）、42.86%（14 人）、60.70%（743 人）、67.81%（1,423 人）、56.96%（1,020 人）、25.69%（109 人）。以最高一方計：高等教育 59.04%（603 人）、中等教育完成 64.67%（1,019 人）、中學以下 66.22%（1,282 人）、小學或以下 51.39%（613 人）、未填 23.71%（97 人）。[D2]

形狀是倒 U，不是階梯。整體檢定（五個實質級）：母親 χ² = 36.85、df = 4、p = 1.933×10⁻⁷、η = 0.1026；父親 χ² = 39.94、p = 4.457×10⁻⁸、η = 0.1065。逐級對其餘的精確檢定經 BH 校正後，母親的中等教育完成（OR 1.276，p_bh 0.00417）與中學以下（OR 1.412，p_bh 4.395×10⁻⁶）較高，小學或以下較低（OR 0.7008，p_bh 1.89×10⁻⁵），高等教育與其餘無分別（OR 0.9857，p_bh 0.9193）；父親的中學以下較高（OR 1.631，p_bh 1.493×10⁻¹¹），小學或以下較低（OR 0.7983，p_bh 0.005609），高等教育僅在邊緣（OR 0.7833，p_bh 0.06245）。以級別作次序變數測梯度，母親 ρ = −0.0511（p = 0.002469，n = 3,503）、父親 ρ = −0.00863（p = 0.6087，n = 3,521）。母親一側的 p 值雖小，ρ 的量級接近零，屬統計顯著而實質不顯著；「學歷越多越好」的單調版本因此不成立：文化資本的量不是它的效力。[D2]

效果量與分解。學歷單獨的 McFadden R² 為 0.0279746，此為總效應；財務三標記為 0.2227331；兩者並置為 0.2384524，故共同解釋的部分為 0.0122554，占學歷總效應的 43.81%。不經財務標記的部分為 0.0157192（LRT p = 2.547×10⁻¹²）；此數在調整的意義上屬直接效應，不可當作文化資本的全部，引用時須標明為 direct。在課程之上再加學歷，ΔR² = 0.0232592（p = 1.302×10⁻¹⁹），故學歷的效應不是課程組成的偽影。以量級言，文化資本的獨立部分 0.0157192 對財務背景的 0.2227331，約為十四分之一。[D2]

兩個可寫的實質命題。第一，中段最高：父母學歷落在中等教育完成至中學以下的學生，畢業率最高（66.03% 與 67.81%），而這批人也是受資助比例最高的一批（33.97% 與 32.61%）。第二，低端最低：小學或以下的子女畢業率為 54.26% 與 56.96%，欠繳率為 16.90% 與 17.16%，兩者都高於其餘各級。[D2]

高等教育父母沒有提高子女的畢業率：母親一側 60.55%（p_bh 0.9193，與其餘無分別），父親一側 55.45%（p_bh 0.06245，僅在邊緣）。可寫的是「沒有證據顯示高等教育父母提高畢業率」；不可寫成「降低」，因為母親一側連方向都不顯著。[D2]

34 未填須單獨處理。母親 127 人、畢業率 24.41%（OR 0.1964，p_bh 1.636×10⁻¹⁶），父親 109 人、25.69%（OR 0.2124，p_bh 3.581×10⁻¹³）；兩者的欠繳率為 21.26% 與 19.27%，獎學金率為 7.874% 與 5.505%。這是一個關於資料收集的陳述：這批學生的家庭背景沒有登記，而其畢業率是全表最低的一批。任何引述學歷效應的句子，都須把它另列或排除。[D2]

限制三條。第一，文化資本只以制度化形式測得，語言與品味的實踐不在欄位內，故本節的結論只覆蓋這一種形式。第二，學歷與入學軌道交纏：父母學歷與「是否 25 歲後入學」的 Cramér V 為 0.3919（母）與 0.3254（父），且入學年齡可能是學歷的下游（延遲入學、重讀、先工作再讀）；在因果次序未定之前按年齡分層會切斷路徑，故本節不作任何年齡調整，交纏本身列為限制。第三，無識別策略，0.0157192 是關聯，不是文化資本的因果效應。[D2]

對主論點的意義。文化資本是一條存在的通道，但不是主導：總效應 0.0279746、獨立部分 0.0157192，對財務背景的 0.2227331。它的形狀與「越多越好」的預期相反，這一點須在正文寫明；略去之後，文化資本會被寫成單調的加分項，而資料不支持那個形狀。[D2]


## 判準與條件

家境的判準是欠繳與否，欠債作為輔助標記 [Q29]。能力的判準是分數的分位，分組對象為有成績者 [Q27]，期別限於第一與第二學期 [Q34]。顯著性的判準是「統計顯著加上說得出機制」，門檻待數據 [Q20]。

「主導」的三條判準並用，因而任何一層的「主導」聲明都附三個數字性條件：解釋力數值、機制陳述、否證條件 [Q38]。

外推句以推論的身分出現：結論所依靠的是約束結構在各地相似，其證偽條件是多地、多份資料的比對 [Q23][Q33]。

年齡分段的解釋附否證條件：以更大的 40 歲以上樣本重測，若方向反轉，該段結論即失效 [Q42]。

## 反駁：能力是決定畢業的主導因素

這個說法的最強形態可以完整寫出。第一，學校的功能是傳授與考核知識，畢業與否由學分與成績決定；第二，能力是成績的直接來源，家境只是背景；第三，資料中與畢業相關最強的欄位確實是通過科目數與平均成績——`pass2` 的 |r| 為 0.7046、`avg_grade` 為 0.5508，兩者都是能力這一層的量度；第四，因此把家境與年齡並列為「同等重要的因素」，是對效果大小的誤讀。

第四步的推論在兩個地方斷開。第一處在時間：第二學期成績與退學在同一學期內發生，二者共享同一段時間，成績因此是退學的同代人而非前因；把同代人的相關讀成因果，等於用結果解釋結果 [Q19][Q27]。第二處在量：三層的母體並不相同，年齡帶在 3,630 人上，能力分位在 2,828 人上（該期有成績者）。在 2,828 人這一母體上，能力分位單獨的 R² 為 0.09577、財務三欄為 0.2011，兩者並置為 0.2611，能力的單獨貢獻小於財務的單獨貢獻；年齡帶在自身母體上的 R² 為 0.07557，亦低於財務三欄在 3,630 人上的 0.2227 [Q38]。

由此可以說的只有一句：在這一組欄位與這一個母體上，能力的解釋力小於家境。至於成績這一量度是否低估了能力，紀錄停在「三個時期的角色」這一項，仍是空白。

## 壓力測試

十三個情境之中，十二個得到可觀察的判準，一個延後。整體的走向是一次收窄：可分析的對象由 4,424 人收至 3,630 人，能力的分位母體收至 2,828 人，財富背景的欄位收至三項。

四項裁決改變了分析設計。審核表的目標由「退學對非退學」改為「已畢業對已退學」，與正文同一分母 [Q24][S01]。曲線由按名次改為按人 [Q34][S08]。宏觀三欄降為控制變數 [Q37][S11]。離鄉就學與國際生退出財富背景，只留在社會背景一側 [Q39][S13]。

一項裁決撤回了結論。語言與文化隔閡一路，原本以按國籍分組觀察；按國籍切開後，可比較的外籍學生只有 86 人，最大的西語圈為 11 人，退學率 54.55%，與本地 39.19% 的 Fisher 精確檢定 p = 0.3586；以 80% 檢定力驗出此差距，每組約需 162 人。該機制的邏輯保留，結論撤回 [Q31][S05]。

一項裁決改寫了機制。婚姻狀況在 30–39 歲一段與退學率相關（已婚 56.86%、單身 68.40%，p = 0.0245），在 40 歲以上一段落在誤差之內（53.04%、64.08%，p = 0.1301）；家庭負擔之說因此讓位於「收入＋儲蓄」，後者的解釋力為 0.2227 對 0.07557 [Q36][S10]。

尚未回答的一項是 S09：十頁上限容納三層時，被移出正文的那一層在結論中的地位。該項停留在「實際撰寫報告的時候再考慮」[Q35][S09]。

## 尚未確立的
