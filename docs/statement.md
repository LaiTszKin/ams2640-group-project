# 陳述文：財富、社會背景與能力對畢業率的影響

分析母體為葡萄牙高等院校 4,424 名學生紀錄中的 3,630 人（已畢業與已退學；在讀 794 人另計）。全文的比率取四位有效數字，計數取整數；每一節的數值均由 `programs/R/` 下的編號程式產生，對應表列於節末。

## 1. 摘要

本研究以 UCI 學生退學與畢業資料，把影響畢業率的因素分為財富背景、社會背景與能力三層，並在同一母體上比較三者的解釋力。結論是：財務狀況與畢業的關聯最強（McFadden R² = 0.2227），能力的獨立貢獻次之（在財務之上增量 0.05999），文化資本的獨立貢獻最小（0.0157）且不呈單調。據此，本研究提出三項判準：以繳費能力與資助資格為校內監測的第一順位，把父母學歷與職業降為背景變項，並要求每一項結論附上可否證的條件。

## 2. 能力對學生畢業率的影響

能力在本研究以在校成績的分位量度，不以單一成績定值，而按期取點。第二學期的成績四分位（每組 707 人，母體 2,828；該期零分的 802 人由分組中剔除，其中 727 人為退學者）之畢業率依序為 51.77%、76.94%、83.88%、89.25%。首尾相差 37.48 個百分點，且四組的次序無例外。兩期之間的組別移動顯示能力是一個過程而非定值：第一學期各組升入第二學期各組的人數矩陣中，對角線為 396、285、313、477，跨組移動的規模與對角線同級。

能力的獨立貢獻以邏輯迴歸量度。在 2,828 人的同一母體上，能力分位單獨的 McFadden R² 為 0.09577，財務三欄為 0.2011，兩者並置為 0.2611。故能力在財務之上的增量為 0.05999，兩者共同解釋的部分為 0.03579，占能力總效應的 37.4%；其餘 62.6% 不與財務重疊。作為對照，入學成績分位的 R² 為 0.004952、曲線下面積 0.5463，故入學前的學術資訊幾乎不含退學資訊，能力的效力集中在同期。

兩項約束須與上述數字同寫。第一，第二學期成績與退學在同一學期內發生，二者共享同一段時間，故 0.05999 是同代關聯，不是能力的先前效應；把同代人的相關讀成因果，等於用結果解釋結果。第二，資料沒有考試難度、科目選擇與教師評分標準，故此量度只覆蓋在校表現的一種形式。

*來源：`model_comparison.csv`、`ability_quartiles.csv`、`ability_transitions.csv`。*

## 3. 社會背景對學生畢業率的影響

### 分論點 1：文化資本

文化資本在此只取制度化的一種形式，即父母的最高學歷；語言與品味那兩種實踐形式不在欄位之內。教育程度依官方碼併為五級（高等教育、技術高等教育、中等教育完成、中學以下、小學或以下），另有未填碼。

父母學歷的總效應為 R² = 0.02797。其中與財務三標記重疊的部分為 0.01226（占 43.81%），不經財務標記的部分為 0.01572（LRT p = 2.547×10⁻¹²）。後者是文化資本的獨立量，但須標明為直接效應：在調整的意義上，它已經扣除了財務路徑，故不可當作文化資本的全部。以量級言，0.01572 對財務背景的 0.2227，約為十四分之一。

形狀不呈階梯，而呈倒 U。母親一側的畢業率為高等教育 60.55%、中等教育完成 65.21%、中學以下 66.03%、小學或以下 54.26%；父親一側為 55.45%、60.70%、67.81%、56.96%。以級別作次序變數測梯度，母親 ρ = −0.05113、父親 ρ = −0.008631，兩者量級皆接近零。可寫的命題只有三條：中段最高（66.03% 與 67.81%），低端最低（54.26% 與 56.96%，欠繳率 16.90% 與 17.16% 亦為各級最高），而高等教育父母沒有提高子女的畢業率（母親 p_bh = 0.9193，父親 p_bh = 0.06245）。「學歷越多越好」的單調版本因此不被支持：文化資本的量不是它的效力。

未填碼須另列。母親 127 人、畢業率 24.41%，父親 109 人、25.69%，皆為全表最低；其欠繳率 21.26% 與 19.27%、獎學金率 7.874% 與 5.505%，與其餘各級不同。此為關於資料收集的陳述，不是教育程度的效應。

限制有三。文化資本只以制度化形式測得，故本節結論只覆蓋這一種形式。父母學歷與入學軌道交纏（與「是否 25 歲後入學」的 Cramér V 為 0.3919 與 0.3254），且入學年齡可能是學歷的下游；按年齡分層會切斷路徑，故本節不作任何年齡調整，交纏本身列為限制。最後，研究沒有識別策略，0.01572 是關聯而非因果效應。

*來源：`qualification_by_parent.csv`、`qualification_models.csv`、`qualification_gradient.csv`、`qualification_entanglement.csv`、`highest_parent_education.csv`。*

### 分論點 2：婚姻狀況與家庭狀況（入學年齡）

入學年齡與畢業率的關係非單調。各帶的退學率依序為：20 歲以前 25.23%（1,621 人）、20–24 歲 36.88%（1,033 人）、25–29 歲 69.30%（355 人）、30–39 歲 64.02%（403 人）、40 歲以上 58.26%（218 人）；頂點落在 25–29 歲。年齡帶單獨的 R² 為 0.07557（四帶參數化）與 0.0839（五帶），低於財務三欄的 0.2227。

此形狀可由「收入穩定性與財富存量」的組合解釋。各帶的欠繳率依序為 6.724%、12.00%、27.89%、24.57%、25.23%；25–29 與 40 歲以上的欠繳率落在同一個區間（勝算比 1.146，p = 0.4987），兩者的退學率則可分（勝算比 1.617，p = 0.008781）。同樣的財務存量而結果不同，故須另有一條路徑；收入穩定性的差異是該路徑的候選，而其否證條件為：以更大的 40 歲以上樣本重測，若方向反轉，該段結論即失效。

婚姻狀況只在 30–39 歲一段與退學相關：已婚 56.86%、單身 68.40%（p = 0.0245）；40 歲以上一段為 53.04% 與 64.08%（p = 0.1301），落在誤差之內。20 歲以前、20–24 歲、25–29 歲三段的已婚人數為 9、13、37 人，樣本不足，不出檢定。婚姻的效應只在中年一段成立、在較年長一段不成立，故「家庭負擔」之說讓位於「收入與儲蓄」的解釋；把婚姻狀況當作年齡層的機制，是本研究拒絕的讀法。

兩項約束。第一，本節的年齡帶與學歷交纏，故不宣稱兩者的獨立分工，只宣稱各自與畢業的關聯。第二，退學的理由在紀錄中為空白，資料只記錄結果與同期成績，故「收入穩定性」是解釋而非已測的變項。

*來源：`age_bands.csv`、`age_tests.csv`、`marriage_strata.csv`、`model_comparison.csv`。*

## 4. 財富背景對學生畢業率的影響

### 分論點 1：父母職業如何經家庭財務狀況導致欠繳與退學

父母職業是收入背景唯一可用的代理，其作用位置在鏈條的上游，不與繳費並列為第二個入口。職業對資助資格的梯度清楚：高層與專業家庭的獎學金持有率為 9.309%（母）與 7.985%（父），非技術家庭為 32.74% 與 33.91%，工業建築技工家庭為 40.35% 與 39.15%（母親一側 χ² = 111.8、p = 8.681×10⁻²²、η = 0.1813；父親一側 χ² = 119.8、p = 1.821×10⁻²³、η = 0.1933）。職業對繳費記錄的關聯則弱（η = 0.06233 與 0.06082），故繳費記錄不宜當作收入水平的代理，它記錄的是財務衝擊的時點。

職業對畢業率的直接關聯不顯著：母親一側 χ² = 9.195（df = 6，p = 0.1629），父親一側 χ² = 14.54（p = 0.02411）；二十二個「單組對其餘」的精確檢定經 BH 校正後，只有父親的工業建築技工一組通過（67.26%，n = 562，p_bh = 0.002589），而該組的優勢在控制繳費之後消失（勝算比 0.9963，p = 0.9746）。以職業直接預測畢業，測到的是收入的粗糙代理，不是收入本身。

鏈條的中段是本研究最強的關聯。欠繳學費者的畢業率為 5.967%（486 人），未欠繳者為 69.34%（3,144 人），相差 63.37 個百分點；欠債者為 24.46%（413 人），未欠債者為 65.53%（3,217 人）。以「欠繳」與「欠債」交叉的四格，退學率為 95.13%（226 人）、93.08%（260 人）、51.87%（187 人）、29.32%（2,957 人），兩欄的 phi 為 0.4349。欠繳這一欄的時點早於任何退學結果，因其屬入學時已知的社經欄位，故鏈條的方向可以寫成由財務狀況指向退學。

書寫規則在此必須明寫：職業在上游、繳費在中游、畢業在下游，故把中游（繳費）當作控制變項、再宣稱上游（職業）無效，是切斷路徑而非檢定路徑。本節因此分列兩個數：職業對畢業的總效應，以及經財務標記的部分；不以後者替代前者。

*來源：`occupation_by_parent.csv`、`occupation_financial.csv`、`occupation_tests.csv`、`financial_markers.csv`、`wealth_four_cell.csv`、`financial_cross.csv`。*

### 分論點 2：獎學金對學生的緩衝作用

在同一份資料中，資助是唯一能把財務壓力與退學分開的變項。獎學金持有者的畢業率為 86.17%（969 人），未持有者為 51.63%（2,661 人），相差 34.54 個百分點。兩者與欠繳交叉之後，跨度進一步拉開：欠繳且未受助者的畢業率為 4.454%（449 人），未欠繳而受助者為 88.63%（932 人），兩端相差 84.18 個百分點。受助者的欠繳率為 3.818%（37/969），未受助者為 16.87%（449/2,661），前者約為後者的四分之一。

兩項判讀須與上述數字同寫。第一，獎學金的制度性質（是否為須審查的資助）尚未以制度文件核實；若其為須審查的資助，則它同時是收入水平的標記與財務壓力的緩衝，兩個角色不能由這份資料分開。第二，受助者可能本來就較有動機，或被較早識別，故 34.54 與 84.18 是關聯的上界，不是介入的效果量。這兩點使「資助提高畢業率」只能寫成與資料相容的讀法，其否證條件為：在控制入學成績與第一學期成績之後，資助的關聯若消失，則緩衝之說不成立。

若以這兩段合起來看，財富背景的影響順序是明確的：繳費與資助（四格跨度 84.18 個百分點）最強，家境四格（phi 0.4349）次之，父母職業的總效應最弱。三者並非同一件事的三種說法，而是同一條路徑上三個位置的量度；把它們並列會低估上游、高估下游，故本研究只用總效應陳述上游，用直接效應陳述下游。

*來源：`financial_markers.csv`、`financial_cross.csv`、`occupation_financial.csv`、`correlation_audit.csv`。*
