# 陳述文：財富、社會背景與能力對畢業率的影響

本文的分析母體為葡萄牙高等院校 4,424 名學生紀錄中的 3,630 人。這 3,630 人由已畢業與已退學兩類組成。在讀的 794 人另計。三層因素在 3,630 人的同一母體上依次比較。比率取四位有效數字。計數取整數。每一節的數值由 `programs/R/` 下的編號程式產生。對應的表列於節末。

## 1. 摘要

本文的結論是：學生的個人能力不是能否畢業的唯一主導因素。在 3,630 人的分析母體上，三個維度的貢獻以財富背景最大（McFadden R² = 0.2227）。能力的邊際貢獻次之，在財務標記之上增量 0.05999。文化資本最小，增量 0.01572。R² 量一個模型比「只按整體平均去猜每個人」多解釋多少資訊。0 表示模型與「只按整體平均去猜」無異。0.2227 已達本領域的良好水平。0.05999 是在財務三標記的模型之上再加能力分位所多出的部分。0.05999 約為 0.2227 的四分之一。三個 R² 不可相加。三個模型互相重疊。本文比較的是各層在另一層之外多解釋多少。由上述排序導出對績優主義的批評。績優主義把結果讀成個人的定值。績優主義忽略客觀的約束條件。資料顯示績效之外尚有財富與文化兩層。兩層的解釋力合計大於能力一層。故績優主義的客觀局限在於把可補償的條件讀成不可補償的能力。

## 2. 學生能力對畢業率的實際影響

本文追蹤 2,828 名學生在兩個學期的成績。本文在第二學期把成績切成四組。四組的畢業率隨分位由低至高逐級上升，依序為 51.77%、76.94%、83.88%、89.25%。數據的產生方式是分期取點。能力貫穿在學期間並持續變動，單一時點的分數只截取在學期間的一段。量度因此改為第一與第二學期各取一點。第二學期的四分位每組 707 人。第二學期零分的 802 人由分組中剔除。802 人之中有 727 人為退學者。解讀上，成績最低組每兩人約有一人畢業。次低組四人中有三人。再上一組五人中有四人。最高組十人中有九人。四組的首尾相差 37.48 個百分點。四段之中沒有逆轉。

背後的機制是分組會移動。第一學期各組升入第二學期各組的人數矩陣中，對角線為 396、285、313、477。對角線指留在原組的人數。跨組移動的規模與對角線同級。若分位是固定的標籤，跨組移動應遠少於對角線。實測跨組移動與對角線相當。故成績所標記的能力是一個可互換的位置，而非一個人的定值。

分組可互換這一現象造成的影響鏈條分兩步量度。第一步是獨立貢獻。在 2,828 人的同一母體上，能力分位單獨的 R² 為 0.09577。財務三標記的 R² 為 0.2011。能力分位與財務三標記並置的 R² 為 0.2611。0.2611 減去 0.2011 得 0.05999。第二步是重疊。能力分位與財務三標記共同解釋的為 0.03579。0.03579 占能力總效應的 37.4%。餘下的 62.6% 落在財務標記之外。若能力只是財務的替身，共同部分應接近能力總量。實測共同部分只占三成七。故能力有六成以上的解釋力不由財務供給。

對照量把效力的位置定下來。入學成績分位的 R² 為 0.004952。入學成績分位的曲線下面積為 0.5463。曲線下面積 0.5 等於丟硬幣，1 等於完全分得開。這兩個量顯示入學前的學術資訊幾乎不含退學資訊。同期能力分位的 R² 為 0.09577。能力分位的 R² 與入學成績分位的 R² 相差約十九倍。

上述三個量得出三句結論。第一，能力有獨立於財務的解釋力。第二，能力解釋力的量級小於財富背景。第三，能力的效力來自在校期間，而非入學時已定的潛質。

另有一項性質與一項邊界。0.05999 的性質限於同代關聯，因為第二學期成績與退學在同一學期內發生。成績與退學共享同一段時間。因果讀法須以先前資訊另行識別。被剔除的 802 人之中約九成退學。故上述比較的對象是仍在校者之間的差異。

*來源：`model_comparison.csv`、`ability_quartiles.csv`、`ability_transitions.csv`。*

## 3. 財富背景對學生畢業率的影響

### 分論點 1：父母職業如何經欠繳學費導致制度性的退學

父母職業揭示家庭的收入位置。收入有限的家庭在遇到外部衝擊時更容易斷繳學費。斷繳學費進而觸發制度性的退學處置。

數據的產生方式是兩步。第一步，本文依官方職業字典把父母的職業併為七個實質階級。第二步，本文比較各階級的獎學金持有率與繳費記錄。高層與專業家庭的獎學金持有率為 9.309%（母）與 7.985%（父）。非技術家庭為 32.74% 與 33.91%。工業建築技工家庭為 40.35% 與 39.15%。按人話讀，高層與專業家庭每十人一人。非技術家庭每三人一人。工業建築技工家庭每五人兩人。

梯度的強度由 η 說明。η 的 0 為無關。η 的 1 為完全對應。母親一側 χ² = 111.8、p = 8.681×10⁻²²、η = 0.1813。父親一側 χ² = 119.8、p = 1.821×10⁻²³、η = 0.1933。0.1813 與 0.1933 屬中等。中等強度足以傳遞訊號。中等強度不單獨決定結果。

背後的機制是職業的訊號沿資助資格下行。同一組職業對欠繳率的關聯為 η = 0.06233 與 0.06082。0.06233 與 0.06082 約為資助梯度的三分之一。這兩個 η 屬弱。職業對畢業的直接關聯亦落在門檻邊緣。母親一側 χ² = 9.195（df = 6，p = 0.1629）在誤差之內。父親一側 χ² = 14.54（p = 0.02411）存在差別。該差別的總量不大。

個別組的檢定把這一點確定下來。二十二個「單組對其餘」的檢定經校正後只有父親的工業建築技工組過關。工業建築技工組的畢業率為 67.26%，n = 562，p_bh = 0.002589。工業建築技工組的優勢在控制繳費之後消失。該檢定的勝算比為 0.9963，p = 0.9746。勝算比 1 表示兩組機會相同。

職業訊號沿繳費下行所造成的影響鏈條落在下游。這一段是全份資料最強的一段。欠繳學費者的畢業率為 5.967%（486 人）。未欠繳者的畢業率為 69.34%（3,144 人）。欠繳者與未欠繳者相差 63.37 個百分點。欠繳者每一百人只有約六人畢業。未欠繳者接近七十人。欠債者的畢業率為 24.46%（413 人）。未欠債者的畢業率為 65.53%（3,217 人）。

以「欠繳」與「欠債」交叉可得四格。四格的退學率為 95.13%（226 人）、93.08%（260 人）、51.87%（187 人）、29.32%（2,957 人）。欠繳與欠債兩欄的 phi 為 0.4349。phi 的 0 為無關。phi 的 1 為完全對應。0.43 屬強。

上述數字導出的結論是：財務狀況與退學的關聯強於任何單一背景變項。欠繳欄的時點早於任何退學結果。故鏈條的方向由財務狀況指向退學，而非由退學回推財務。以職業直接預測畢業所測得的，是收入的粗糙代理。

*來源：`occupation_by_parent.csv`、`occupation_financial.csv`、`occupation_tests.csv`、`financial_markers.csv`、`wealth_four_cell.csv`、`financial_cross.csv`。*

### 分論點 2：獎學金對學生的緩衝作用

獎學金在短期欠繳發生時提供緩衝。獎學金的跨度揭示了財富對畢業的重要性。

數據的產生方式是分組比較。本文先算獎學金持有者與未持有者的畢業率。本文再把兩組與欠繳交叉。獎學金持有者的畢業率為 86.17%（969 人）。未持有者的畢業率為 51.63%（2,661 人）。獎學金持有者與未持有者相差 34.54 個百分點。按人話讀，受助者每十人約有八人半畢業。未受助者每十人約五人。

背後的機制是資助的雙重角色。受助者的欠繳率為 3.818%（37/969）。未受助者的欠繳率為 16.87%（449/2,661）。3.818% 約為 16.87% 的四分之一。故資助在資料中標記收入水平。資助亦在衝擊發生時吸收短期欠繳。

資助造成的影響鏈條有兩個環節。第一環，資助資格高則欠繳率低。第二環，欠繳率低則退學率低。交叉之後，欠繳且未受助者的畢業率為 4.454%（449 人）。未欠繳而受助者的畢業率為 88.63%（932 人）。兩端相差 84.18 個百分點。欠繳且未受助者每一百人約有四人畢業。未欠繳而受助者接近九十人。84.18 這個跨度大於欠繳欄的 63.37。故資助一欄所量到的差距比繳費一欄更寬。

結論須附條件。獎學金的制度性質須以制度文件核實，核實的內容是它是否為須審查的資助。核實之前獎學金同時是收入標記與壓力緩衝。兩個角色的比重由制度文件決定。受助者亦可能本來就較有動機。受助者亦可能被較早識別。選拔效應因此混入 34.54 與 84.18 這兩個差距。兩項合起來使「資助提高畢業率」成為與資料相容的讀法。資助緩衝之說的否證條件為：在控制入學成績與第一學期成績之後，資助的關聯若消失，則緩衝之說與資料不符。

*來源：`financial_markers.csv`、`financial_cross.csv`、`occupation_financial.csv`、`correlation_audit.csv`。*

## 4. 社會背景對學生畢業率的影響

### 分論點 1：父母文化資本對畢業率的影響

父母學歷以制度化形式量度文化資本。父母學歷的效應存在。父母學歷的效應形狀與「學歷越多越好」的預期相反。

數據的產生方式是嵌套模型。父母學歷單獨的 R² 為 0.02797。財務三標記的 R² 為 0.2227。父母學歷與財務三標記並置的 R² 為 0.2385。並置的增量為 0.01226。學歷效應中有 43.81% 與財務重疊。餘下的 0.01572（LRT p = 2.547×10⁻¹²）落在財務路徑之外。0.01572 是唯一可歸於文化資本的獨立量。0.01572 的 p 值遠小於 0.05。故「學歷在財務之外毫無作用」一說超出誤差範圍。0.01572 的量級為 0.2227 的十四分之一。

背後的機制須分形狀與軌道兩層。形狀上，母親一側的畢業率為高等教育 60.55%、中等教育完成 65.21%、中學以下 66.03%、小學或以下 54.26%。父親一側的畢業率為 55.45%、60.70%、67.81%、56.96%。母親一側與父親一側一致地中段最高、兩端低。以級別作次序變數測梯度，母親 ρ = −0.05113，父親 ρ = −0.008631。ρ 為正表示學歷愈高畢業率愈高。母親與父親的 ρ 皆為負而量級近零。故單調版本與資料不符。

軌道的分析給出另一層。父母學歷與「是否 25 歲後入學」的 Cramér V 為 0.3919 與 0.3254。0.3919 與 0.3254 已超過 0.3 的強度線。故高學歷父母與子女按常規年齡入學在資料中同時出現。

父母學歷的影響止於兩處。第一處在低端：低端的欠繳率 16.90% 與 17.16% 為各級最高。故低學歷家庭的低畢業率與財務弱勢同時出現。第二處在高等教育一級：母親 p_bh = 0.9193，父親 p_bh = 0.06245，兩者皆大於 0.05。故高等教育一級量不出方向。

另有一段須與學歷效應分開的陳述。未填碼一級母親 127 人、畢業率 24.41%。父親 109 人、畢業率 25.69%。兩者皆為全表最低。未填碼一級的欠繳率 21.26% 與 19.27% 高於五個實質級的上界（16.90% 與 21.43%）。未填碼一級的獎學金率 7.874% 與 5.505% 低於下界（9.382% 與 7.143%）。故「家庭背景未登記」本身是一個弱勢標記。

結論是三句。第一，文化資本對畢業率有直接效應。0.01572 的量級最小。0.01572 不經財務路徑。第二，父母學歷與畢業率的關係非單調。中段家庭的畢業率高於高學歷家庭。第三，三項限制界定 0.01572 的範圍。0.01572 只覆蓋制度化形式。父母學歷與入學軌道交纏。故年齡變項只列為限制、不進模型。本研究沒有識別策略，0.01572 的性質限於關聯。

*來源：`qualification_by_parent.csv`、`qualification_models.csv`、`qualification_gradient.csv`、`qualification_entanglement.csv`、`highest_parent_education.csv`。*

### 分論點 2：入學年齡與家庭狀況對畢業率的影響

入學年齡與家庭狀況構成第三條與畢業相關的社會背景線。入學年齡的解釋力低於財富背景，形狀呈中間高、兩端低。

數據的產生方式是按入學年齡分帶。本文在每帶內比較退學率與繳費記錄。各帶的退學率依序為 20 歲以前 25.23%（1,621 人）、20–24 歲 36.88%（1,033 人）、25–29 歲 69.30%（355 人）、30–39 歲 64.02%（403 人）、40 歲以上 58.26%（218 人）。按人話讀，依次為每四人一人、每三人一人、每三人兩人、每三人兩人、每兩人一人。頂點落在 25–29 歲。量級由 R² 說明：年齡帶單獨的 R² 為 0.07557（四帶）與 0.0839（五帶）。0.07557 與 0.0839 相當於財務三標記 0.2227 的 0.3393 與 0.3767。故入學年齡的權重低於財富背景。

背後的機制由兩帶的對照暴露。各帶的欠繳率依序為 6.724%、12.00%、27.89%、24.57%、25.23%。欠繳率的形狀與退學率不同。欠繳率自 25–29 歲起進入高位並在高位停留。退學率則在 25–29 歲見頂後回落。25–29 與 40 歲以上的欠繳率落在同一區間（勝算比 1.146，p = 0.4987）。25–29 與 40 歲以上的退學率則可分（勝算比 1.617，p = 0.008781）。同一財務存量而結果不同。故退學的差異須另有一條路徑。收入穩定性的差異是這條路徑的候選。

收入穩定性的影響鏈條延伸到家庭狀況。婚姻狀況與退學的關聯只在 30–39 歲一段成立。30–39 歲一段的已婚者退學率 56.86%，單身者退學率 68.40%（p = 0.0245）。已婚者與單身者相差近十二個百分點。40 歲以上一段的已婚者退學率 53.04%，單身者退學率 64.08%（p = 0.1301）。40 歲以上一段的差距絕對值相若而落入誤差。20 歲以前、20–24 歲、25–29 歲三段的已婚人數為 9、13、37 人。樣本不足，檢定不作。

結論是兩句。第一，入學年齡與家庭狀況是獨立的關聯來源。入學年齡與家庭狀況的權重低於財富背景。故單層不足以支撐「主導」的判斷。第二，收入穩定性停留在解釋而非已測的變項。「家庭負擔」之說由此讓位於「收入與儲蓄」。婚姻狀況列為年齡層的描述變項。收入穩定性的解釋成立依賴否證條件：以更大的 40 歲以上樣本重測，若 25–29 與 40 歲以上兩帶的方向反轉，收入穩定性的解釋即失效。退學的理由在紀錄中為空白。年齡帶與學歷亦交纏。故本節只陳述年齡帶、學歷各自與畢業的關聯。

*來源：`age_bands.csv`、`age_tests.csv`、`marriage_strata.csv`、`model_comparison.csv`。*

## 5. 總結

三層的關聯在合併之後排定。財富背景最強（0.2227）。能力次之，單獨 0.09577，在財務之外只增 0.05999。文化資本最小（0.01572）。個人際遇一層的解釋力為 0.07557，介於能力與文化資本之間。個人際遇一層由入學年齡與家庭狀況組成。三層的母體不同。比較只作量級之用。排序在方向上是穩定的。

學術能力因此不宜成為唯一考量。財富背景對畢業率的單獨影響大於能力對畢業率的單獨影響。能力在財務之外的增量有限。個人際遇與財富背景合起來的解釋力高於能力的單獨貢獻。若以能力作為畢業資格的唯一判準，被制度篩掉的將主要是財務與際遇處於不利位置的學生，而非能力較低者。這正是績優主義的客觀局限。績優主義把可補償的條件讀成不可補償的能力。

由上述三層排序導出三項判準。第一，校內監測以繳費能力與資助資格為第一順位。繳費與資助兩個標記的跨度最大，分別為 84.18 與 63.37 個百分點。繳費與資助的時點早於退學。故繳費與資助可在制度性退學發生之前介入。第二，父母學歷與父母職業降為背景變項。父母學歷與父母職業的用途限於識別弱勢。父母學歷與父母職業不用於預測個別學生的結果。第三，資源應放在讓弱勢學生以學術能力脫離困境的通道上。資助在衝擊發生時吸收短期欠繳。能力則在在校期間累積。資助與能力的接合處正是政策可施力之處。每一項結論皆附否證條件。故三項判準可隨新資料修正。
