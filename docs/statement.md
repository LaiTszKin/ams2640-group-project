# 陳述文：財富、社會背景與能力對畢業率的影響

本文使用的資料來自葡萄牙高等院校的學生紀錄，共 4,424 人。資料分為已畢業者、已退學者與仍在讀者三類；由於仍在讀的 794 人尚未出現最終學業結果，故不納入比較，分析母體由已畢業者與退學者共 3,630 人組成。三層因素皆在同一份資料上比較，惟財富背景與文化資本在 3,630 人上計算，能力則在 2,828 人上計算，各節將逐一註明母體。

## 1. 摘要

學生個人的學術能力不足以單獨決定其能否順利畢業。基於分析母體的實證結果，在財富、文化與能力三個維度之中，財富背景對學生畢業率有著最大的單獨貢獻：在 3,630 人的母體上，財務三標記的 McFadden R² 達 0.2227，已屬本領域的良好解釋水平；相較之下，能力的邊際貢獻次之，在 2,828 人的母體上將能力分位加入財務模型後，R² 僅上升 0.05999；文化資本的邊際貢獻最小，在 3,630 人的母體上加入父母學歷後，R² 只上升 0.01572。由於三個模型的解釋範圍互相重疊，0.05999 與 0.01572 皆為消除重疊後相較財務模型的額外解釋力，不可與 0.2227 直接相加，但足以確立「財富＞能力＞文化」的解釋力排序。由上述排序可導出對績優主義的根本批評：績優主義將個人最終的學業結果直接歸因於固有能力，卻忽略家庭財務狀況與父母教育水平等客觀約束條件；當財富與文化兩層的解釋力合計大於能力一層時，績優主義的客觀局限便在於它把可以補償的外部條件，誤讀為不可補償的個人能力。

## 2. 學生能力對畢業率的實際影響

本研究追蹤 2,828 名學生在兩個學期的成績變化，發現學業能力雖然對畢業率有獨立的解釋力，但其影響力遠小於財富背景，且效力主要集中於入學後的在校期間。在數據產生與解讀方面，由於能力在學期間持續變動，單一時點的分數無法反映全貌，故研究取第一與第二學期兩點作對照，並將第二學期有成績的 2,828 人按分數由低至高四等分（每組 707 人，剔除無法排序的 802 名零分者）。四組的畢業率由低至高依序為 51.77%、76.94%、83.88% 與 89.25%，次序無一反轉，顯示成績越高者畢業率越高。

這一現象背後的機制在於「能力分組的可移動性」。在第一學期升入第二學期的人數轉移矩陣中，留在原組的對角線人數依序為 396、285、313、477，跨組移動的人數與留組人數相當，證明成績所標記的能力是一個動態可變的位置，而非固定不變的個人屬性。這種可移動性衍生出兩層實際影響鏈條：其一，在 2,828 人的同一母體上，單獨放入能力分位的 R² 為 0.09577，單獨放入財務三標記的 R² 為 0.2011，兩者並置則為 0.2611。兩者共同解釋的部分為 0.03579（占能力單獨 R² 的 37.4%），扣除重疊後，能力在財務之外仍保有 0.05999 的獨立額外解釋力（超過六成不被財務取代）。其二，對比入學前的學術資訊，入學成績分位的 R² 僅 0.004952、曲線下面積為 0.5463（接近隨機猜測的 0.5），而同期能力分位的 R² 為其十九倍，說明能力的效力主要來自在校期間的表現，而非入學前已確定的潛質。

綜上所述，能力並非財務的重複量度，但亦非決定畢業的唯一主導因素；且由於其效力集中於在校期間，政策介入的時機應設於入學之後而非入學之前。同時須注意兩項邊界：0.05999 僅屬同代關聯而非因果判定，且母體已剔除約九成退學的 802 名零分者，故結論僅反映仍在校學生之間的差異。

*來源：`model_comparison.csv`、`ability_quartiles.csv`、`ability_transitions.csv`。*

## 3. 財富背景對學生畢業率的影響

### 父母職業、財務衝擊與制度性退學

父母職業揭示了家庭的收入位置，而收入有限的家庭一旦遭遇失業或收入中斷等外部衝擊，便更容易斷繳學費，進而引發學校依繳費狀態作出的制度性退學處置。本文依官方職業字典將父母職業併為七個實質階級，並在各階級內計算「獎學金持有率」（標記收入位置）與「學費欠繳率」（標記財務衝擊）。數據顯示，獎學金持有率呈現明顯的收入梯度：高層與專業家庭為 9.309%（母）與 7.985%（父），非技術家庭為 32.74% 與 33.91%，工業建築技工家庭則達 40.35% 與 39.15%；職業位置越低，資助持有率越高，母親一側 η = 0.1813（χ² = 111.8，p = 8.681×10⁻²²），父親一側 η = 0.1933（χ² = 119.8，p = 1.821×10⁻²³），屬中等強度的非偶然對應。

然而，職業與欠繳率的直接關聯明顯較弱（η 分別為 0.06233 與 0.06082），對畢業的直接關聯亦多不顯著：母親一側 χ² = 9.195（p = 0.1629）；父親一側雖達顯著（χ² = 14.54，p = 0.02411），且經 BH 校正後僅工業建築技工組過關（畢業率 67.26%，n = 562，校正後 p = 0.002589），但一旦控制繳費狀態，該組優勢隨即消失（勝算比 0.9963，p = 0.9746）。這條邏輯鏈條將父母職業定位於因果上游——職業透過收入位置與繳費狀態向下傳遞訊號，而非直接作用於畢業。

在鏈條下游，財務狀況呈現全份資料最強的關聯：欠繳學費者的畢業率僅 5.967%（486 人），未欠繳者為 69.34%（3,144 人），兩者相差 63.37 個百分點；欠債者畢業率為 24.46%（413 人），未欠債者為 65.53%（3,217 人）。兩欄交叉（phi = 0.4349，屬強關聯）後的四格退學率依序為：同時欠繳又欠債者 95.13%（226 人）、只欠繳者 93.08%（260 人）、只欠債者 51.87%（187 人）、兩項皆無者 29.32%（2,957 人）。由於欠繳時點早於退學結果，時序明確由財務指向退學，證明財務狀況才是決定退學最近且最強的一環。

*來源：`occupation_by_parent.csv`、`occupation_financial.csv`、`occupation_tests.csv`、`financial_markers.csv`、`wealth_four_cell.csv`、`financial_cross.csv`。*

### 獎學金的緩衝作用與財富重要性

獎學金在學生面臨短期學費欠繳時提供關鍵緩衝，其跨度進一步揭示了財富對畢業率的決定性影響。本文分別計算獎學金持有者與未持有者的畢業率並交叉欠繳狀態：受助者畢業率高達 86.17%（969 人），未受助者僅 51.63%（2,661 人），相差 34.54 個百分點。

這項差距背後的機制在於資助的雙重角色：受助者的欠繳率僅 3.818%（37/969），約為未受助者 16.87%（449/2,661）的四分之一，顯示資助既標記家庭的低收入位置，亦在衝擊發生時吸收短期欠繳。由此構成的兩環影響鏈條——「資助資格高 → 欠繳率低 → 退學率低」——在交叉兩端展現出高達 84.18 個百分點的總跨度：欠繳且未受助者的畢業率僅 4.454%（449 人），而未欠繳且受助者則達 88.63%（932 人），遠超單純欠繳一欄的 63.37 個百分點。

因此，資助對畢業率的保護作用在資料中清晰可見，但須附帶兩項條件：其一，獎學金是否屬於須審查的資助須以制度文件核實；其二，受助者可能本來就具備較高動機或較早被學校識別，選拔效應可能混入上述差距。若未來在控制入學與第一學期成績後該關聯消失，則緩衝之說即告否證；在此之前，「資助提高畢業率」是與現有資料相容的合理解讀。

*來源：`financial_markers.csv`、`financial_cross.csv`、`occupation_financial.csv`、`correlation_audit.csv`。*

## 4. 社會背景對學生畢業率的影響

### 父母文化資本對畢業率的影響

父母學歷作為制度化的文化資本，對畢業率存在獨立但微弱的直接效應，且其分布形狀與「學歷越高越好」的直覺預期相反。本文透過嵌套模型分解學歷與財務的解釋力：父母學歷單獨的 R² 為 0.02797，財務三標記為 0.2227，兩者並置為 0.2385。扣除與財務重疊的 0.01226（占學歷總效應 43.81%）後，學歷在財務之外的獨立貢獻僅為 0.01572（LRT p = 2.547×10⁻¹²），顯著異於零但僅為財務解釋力的十四分之一，在三個維度中最小。

在形狀與機制上，畢業率呈現「中段最高、兩端較低」的非單調結構：母親一側的高等教育、中等教育完成、中學以下與小學或以下畢業率依序為 60.55%、65.21%、66.03% 與 54.26%；父親一側依序為 55.45%、60.70%、67.81% 與 56.96%。以次序變數測得的梯度均接近零且呈微負（母親 ρ = −0.05113，父親 ρ = −0.008631），否證了單調遞增的假設。背後的軌道機制在於父母學歷與「是否 25 歲後入學」高度交纏（Cramér V 分別為 0.3919 與 0.3254），高學歷父母與子女按常規年齡入學同時出現。此外，低端學歷家庭伴隨最高的欠繳率（16.90% 與 17.16%），而高等教育一級則量不出方向（母親 p_bh = 0.9193，父親 p_bh = 0.06245）；至於未填碼一級（母親 127 人、畢業率 24.41%；父親 109 人、畢業率 25.69%），其欠繳率高達 21.26% 與 19.27%，反映「家庭背景未登記」本身即為弱勢標記，不應混入學歷效應。

總結而言，文化資本對畢業率確有獨立於財務的直接影響，但其量級最小且關係非單調；同時受限於資料僅涵蓋制度化形式、與入學軌道交纏以及缺乏因果識別策略，0.01572 僅能界定為關聯性證據。

*來源：`qualification_by_parent.csv`、`qualification_models.csv`、`qualification_gradient.csv`、`qualification_entanglement.csv`、`highest_parent_education.csv`。*

### 入學年齡與家庭狀況對畢業率的影響

入學年齡與家庭狀況構成另一條獨立的社會背景線，其解釋力約為財富背景的三分之一，且退學率呈「中間高、兩端低」的倒 U 型分布。本文將學生分為五個入學年齡帶，退學率依序為：20 歲以前 25.23%（1,621 人）、20–24 歲 36.88%（1,033 人）、25–29 歲 69.30%（355 人）、30–39 歲 64.02%（403 人）與 40 歲以上 58.26%（218 人），於 25–29 歲見頂。年齡帶單獨的 R² 為 0.07557（四帶）與 0.0839（五帶），相當於財務三標記 0.2227 的 0.3393 與 0.3767。

對比欠繳率可揭示背後的機制：各帶欠繳率依序為 6.724%、12.00%、27.89%、24.57% 與 25.23%，自 25–29 歲起便維持高位，並未如退學率般在 25–29 歲後回落。針對 25–29 歲與 40 歲以上兩帶的檢定顯示，兩者欠繳機會無顯著差異（勝算比 1.146，p = 0.4987），但 25–29 歲組的退學機會卻是 40 歲以上組的 1.617 倍（p = 0.008781）。這說明在相同的財務存量下，退學差異須由「收入穩定性」等另一路徑解釋。此鏈條亦延伸至家庭狀況：在 30–39 歲組中，已婚者退學率（56.86%）顯著低於單身者（68.40%，p = 0.0245）；40 歲以上組差距相若（53.04% 對 64.08%）但受樣本規模限制未達顯著（p = 0.1301），25 歲以下各組則因已婚人數過少（9 至 37 人）不作檢定。

因此，入學年齡與家庭狀況是獨立但非主導的關聯來源，其影響指向「收入與儲蓄穩定性」而非單純的「家庭負擔」。此解釋仍受限於退學理由空白及年齡與學歷交纏等資料限制，若未來以更大樣本重測 40 歲以上群體而方向反轉，該解釋即告失效。

*來源：`age_bands.csv`、`age_tests.csv`、`marriage_strata.csv`、`model_comparison.csv`。*

## 5. 總結

綜合全篇分析，社會背景與財富背景對畢業率構成了層次分明的結構性約束：財富背景的解釋力最強（R² = 0.2227），個人際遇（入學年齡與家庭狀況）次之（R² = 0.07557），文化資本最小（R² = 0.01572）。雖然各層母體不盡相同，但「財富與際遇主導、文化資本輔助」的排序方向穩定明確。

正因如此，學術能力不應該成為評估學生畢業潛力或分配教育資源的唯一考量因素。單就解釋力而言，財富背景對畢業率的單獨影響已大於學術能力（0.09577，財務外僅增 0.05999）；若將個人際遇與財富背景合起來計算，其對畢業率的影響更遠高於學術能力的單獨貢獻。若制度仍執意以能力作為唯一判準，最終被淘汰的將主要是財務與際遇處於弱勢的學生，而非能力不足者——這正是績優主義把可補償條件誤讀為不可補償能力的根本謬誤。

面對此結構性現實，我們應將政策與校內監測的重心轉向「協助弱勢群體透過學術能力脫離困境」。具體而言：第一，校內預警應以繳費能力與資助資格為第一順位，利用其高達 84.18 與 63.37 個百分點的跨度與時間領先優勢，在制度性退學發生前及早介入；第二，將父母學歷與職業降為輔助識別弱勢的背景變項，避免標籤化預測；第三，將資源精準投放於資助與學術支援的接合處，以獎學金吸收短期財務衝擊，同時為入學後的弱勢學生提供能力累積的通道，使其得以憑藉在校期間的學術表現完成學業。

*註：本文各項結論皆附有明確的否證條件與母體邊界，可隨後續新資料與制度文件進行修正。*
