# 陳述文：財富、社會背景與能力對畢業率的影響

本文的分析母體為葡萄牙高等院校 4,424 名學生紀錄中的 3,630 人，即已畢業與已退學兩類，在讀的 794 人另計。三層因素在此同一母體上依次比較；比率取四位有效數字，計數取整數，每一節的數值由 `programs/R/` 下的編號程式產生，對應表列於節末。

## 1. 摘要

本文的結論是：學生的個人能力不是能否畢業的唯一主導因素。在 3,630 人的分析母體上，三層因素的解釋力排序為財富背景最高（McFadden R² = 0.2227）、能力的邊際貢獻次之（在財務標記之上增量 0.05999）、文化資本的邊際貢獻最小（0.01572）。三個數字出自同一份資料的同一組嵌套模型；能力以同期成績量度，文化資本以父母學歷量度，兩者的量度限制因此寫進各自的段落，並與數字同引。

績優主義的定義在此決定評價的方向。績優主義是對績效的崇拜，其論述把結果讀成個人的定值，而忽略客觀的約束條件；資料顯示績效之外尚有財富與文化兩層，兩層的解釋力合計大於能力一層，故其客觀局限在於把可補償的條件讀成不可補償的能力。依此排序，本文提出三項判準：校內監測以繳費能力與資助資格為第一順位；父母學歷與父母職業降為背景變項；每一項結論附上可否證的條件。

## 2. 能力對學生畢業率的影響

能力的量度方式決定了它能回答的問題。能力貫穿在學期間並持續變動，單一時點的分數只截取其中一段，故量度改為按第一與第二學期各取一點，並以分期分位取代單一成績的定值。第二學期的成績四分位（每組 707 人，母體 2,828，該期零分的 802 人由分組中剔除，其中 727 人為退學者）之畢業率依序為 51.77%、76.94%、83.88%、89.25%；四組由低至高遞增，首尾相差 37.48 個百分點。分位因此是一個可排序的量，其排序與畢業的排序同向。

兩期追蹤把能力界定為過程，同期的性質把它的解釋地位限定在同代。第一學期各組升入第二學期各組的人數矩陣中，對角線為 396、285、313、477，跨組移動的規模與對角線同級，故組別在同一批人身上可以互換，能力因此是持續移動的過程。第二學期成績與退學在同一學期內發生，兩者共享同一段時間，故上述量度只具同代地位，其效力範圍限於同期。

能力的獨立貢獻由嵌套模型的解釋力差量度，結果為 0.05999。在 2,828 人的同一母體上，能力分位單獨的 McFadden R² 為 0.09577，財務三標記為 0.2011，兩者並置為 0.2611；增量 0.05999 是能力在財務標記之外的貢獻，兩者共同解釋的部分為 0.03579，占能力總效應的 37.4%，餘下的 62.6% 落在財務標記之外。能力因此有獨立於財務的解釋力，其量級小於財務一層。

對照量把能力的效力定位在校內。入學成績分位的 McFadden R² 為 0.004952、曲線下面積 0.5463，入學前的學術資訊因此幾乎不含退學資訊；同期能力分位的 R² 為 0.09577，與入學成績相差約十九倍。能力的效力由此集中於在校期間，前述 0.05999 是同期表現的貢獻，而非入學時已定的潛質。

三項限制界定上述數字的範圍。第一，能力與退學同代，0.05999 的性質限於同代關聯，其因果讀法須以先前資訊另行識別。第二，資料記載成績而缺少考試難度、科目選擇與教師評分標準，故量度覆蓋在校表現的一種形式。第三，母體以第二學期有成績者為界，零分的 802 人（其中 727 人退學）被移出分組，故能力的比較對象是「讀到第二學期且有分數」的一群。

*來源：`model_comparison.csv`、`ability_quartiles.csv`、`ability_transitions.csv`。*

## 3. 社會背景對學生畢業率的影響

### 分論點 1：文化資本

文化資本在此以父母的最高學歷操作化，此一操作化覆蓋制度化的形式；語言與品味那兩種實踐形式留待其他資料。父母學歷依官方碼併為五級（高等教育、技術高等教育、中等教育完成、中學以下、小學或以下），另有未填碼一級。分級的目的在於把學制的層級轉成可比較的次序，故各級以年限與學位為界，未填碼另立一級；父母學歷因此是一個次序變項，而非一組互不相干的類別。

學歷的總效應由嵌套模型的解釋力構成，其中經財務標記與不經財務標記的部分可以分開。父母學歷單獨的 McFadden R² 為 0.02797，財務三標記為 0.2227，兩者並置為 0.2385；並置的增量為 0.01226，即學歷效應中有 43.81% 與財務重疊，餘下的 0.01572（LRT p = 2.547×10⁻¹²）落在財務路徑之外。後者是文化資本的獨立量，其性質限於直接效應，因它已扣除財務路徑；以量級言，0.01572 對財富背景的 0.2227 約為十四分之一，故文化資本在三層之中居於末位。

形狀的分析改寫了「學歷越多越好」的假設，資料給出的是倒 U。母親一側的畢業率為高等教育 60.55%、中等教育完成 65.21%、中學以下 66.03%、小學或以下 54.26%，父親一側為 55.45%、60.70%、67.81%、56.96%；兩側的次序皆為中段最高、兩端低。以級別作次序變數測梯度，母親 ρ = −0.05113、父親 ρ = −0.008631，兩者的量級皆接近零，故單調版本與資料不符。由此可寫的命題有三條：中段最高（66.03% 與 67.81%），低端最低（54.26% 與 56.96%，其欠繳率 16.90% 與 17.16% 亦為各級最高），高等教育父母與其餘各級的差異落在誤差之內（母親 p_bh = 0.9193，父親 p_bh = 0.06245）。「提高畢業率」一說在高等教育一級得到的是空白，亦即在這一級，父母的學歷與子女的畢業之間量不出方向。

未填碼構成一段獨立的陳述，須與學歷效應分開。母親 127 人、畢業率 24.41%，父親 109 人、25.69%，兩者皆為全表最低；其欠繳率為 21.26% 與 19.27%（五個實質級的上界為 16.90% 與 21.43%），獎學金率為 7.874% 與 5.505%（五個實質級的下界為 9.382% 與 7.143%）。把這一級併入任何學歷效應的計算，會把「未登記家庭背景」的低畢業率記成教育程度的效力，故本節把它另列為關於資料收集的陳述，並在引用學歷數字時排除。

三項限制界定 0.01572 的範圍。第一，文化資本以制度化形式測得，本節的結論因此只覆蓋這一種形式。第二，父母學歷與入學軌道交纏，其與「是否 25 歲後入學」的 Cramér V 為 0.3919 與 0.3254；按年齡分層會切斷這條路徑，故本節的年齡變項只列為限制，不進模型。第三，本研究沒有識別策略，0.01572 的性質限於關聯。

*來源：`qualification_by_parent.csv`、`qualification_models.csv`、`qualification_gradient.csv`、`qualification_entanglement.csv`、`highest_parent_education.csv`。*

### 分論點 2：婚姻狀況與家庭狀況（入學年齡）

入學年齡與畢業率的關係是一條非單調的曲線，其解釋力低於財富背景。各帶的退學率依序為：20 歲以前 25.23%（1,621 人）、20–24 歲 36.88%（1,033 人）、25–29 歲 69.30%（355 人）、30–39 歲 64.02%（403 人）、40 歲以上 58.26%（218 人），頂點落在 25–29 歲。年齡帶單獨的 R² 為 0.07557（四帶參數化）與 0.0839（五帶），相當於財務三標記 0.2227 的 0.3393 與 0.3767。曲線的形狀與量級合起來顯示：年齡是一個獨立的關聯來源，其權重居於財富背景之下，故單層不足以支撐「主導」的判斷。

曲線由收入穩定性與財富存量的組合解釋，25–29 與 40 歲以上兩帶的對照提供檢定。各帶的欠繳率依序為 6.724%、12.00%、27.89%、24.57%、25.23%；25–29 與 40 歲以上的欠繳率落在同一個區間（勝算比 1.146，p = 0.4987），兩者的退學率則可分（勝算比 1.617，p = 0.008781）。同一財務存量而結果不同，故退學的差異須另有一條路徑，收入穩定性的差異是該路徑的候選；其否證條件為：以更大的 40 歲以上樣本重測，若方向反轉，該段結論即失效。

婚姻狀況與退學的關聯只在 30–39 歲一段成立，並在 40 歲以上一段落入誤差。30–39 歲一段的退學率為已婚 56.86%、單身 68.40%（p = 0.0245）；40 歲以上一段為 53.04% 與 64.08%（p = 0.1301），差距落在誤差之內。20 歲以前、20–24 歲、25–29 歲三段的已婚人數為 9、13、37 人，樣本不足，檢定由此不作。婚姻的關聯在中段成立而在較年長一段落入誤差，故「家庭負擔」之說讓位於「收入與儲蓄」的解釋；婚姻狀況由此列為年齡層的描述變項，其機制地位由本研究拒絕。

兩項限制界定本節的陳述範圍。第一，年齡帶與學歷交纏，故本節只陳述兩者各自與畢業的關聯，其獨立分工留待另立的研究設計。第二，退學的理由在紀錄中為空白，收入穩定性因此是解釋而非已測的變項，其成立依賴前述否證條件。

*來源：`age_bands.csv`、`age_tests.csv`、`marriage_strata.csv`、`model_comparison.csv`。*

## 4. 財富背景對學生畢業率的影響

### 分論點 1：父母職業如何經家庭財務狀況導致欠繳與退學

父母職業是收入背景唯一可用的代理，其解釋力表現在資助資格一端，繳費記錄則標記衝擊的時點。高層與專業家庭的獎學金持有率為 9.309%（母）與 7.985%（父），非技術家庭為 32.74% 與 33.91%，工業建築技工家庭為 40.35% 與 39.15%（母親一側 χ² = 111.8、p = 8.681×10⁻²²、η = 0.1813；父親一側 χ² = 119.8、p = 1.821×10⁻²³、η = 0.1933）。職業對資助資格的梯度由此確立；同一組職業對欠繳率的關聯為 η = 0.06233 與 0.06082，繳費記錄的用途因此限於標記財務衝擊的時點。兩端合起來顯示：職業在鏈條的上游，其訊號經資助資格傳遞。

父母職業對畢業率的直接關聯落在顯著門檻之外，其效應經財務標記傳遞。母親一側 χ² = 9.195（df = 6，p = 0.1629），父親一側 χ² = 14.54（p = 0.02411）；二十二個「單組對其餘」的精確檢定經 BH 校正後，只有父親的工業建築技工一組通過（67.26%，n = 562，p_bh = 0.002589），而該組的優勢在控制繳費之後消失（勝算比 0.9963，p = 0.9746）。單組的優勢可被繳費吸收，職業的作用位置因此在財務之上游；以職業直接預測畢業所測得的，是收入的粗糙代理，而非職業本身的效力。

鏈條的中段是全份資料最強的關聯，欠繳與退學的距離由此量出。欠繳學費者的畢業率為 5.967%（486 人），未欠繳者為 69.34%（3,144 人），相差 63.37 個百分點；欠債者為 24.46%（413 人），未欠債者為 65.53%（3,217 人）。以「欠繳」與「欠債」交叉的四格，退學率為 95.13%（226 人）、93.08%（260 人）、51.87%（187 人）、29.32%（2,957 人），兩欄的 phi 為 0.4349。欠繳這一欄的時點早於任何退學結果，故鏈條的方向寫成由財務狀況指向退學。

書寫規則由鏈條的方向導出：上游用總效應，下游用直接效應。職業在上游、繳費在中游、畢業在下游，把中游當作控制變項再宣稱上游無效，所作的處置是切斷路徑；本節因此分列兩個數，職業對畢業的總效應與經財務標記的部分各自呈現，後者在文中的用途限於描述路徑分工。

*來源：`occupation_by_parent.csv`、`occupation_financial.csv`、`occupation_tests.csv`、`financial_markers.csv`、`wealth_four_cell.csv`、`financial_cross.csv`。*

### 分論點 2：獎學金對學生的緩衝作用

資助是唯一能把財務壓力與退學分開的變項，其跨度大於欠繳。獎學金持有者的畢業率為 86.17%（969 人），未持有者為 51.63%（2,661 人），相差 34.54 個百分點。兩者與欠繳交叉之後，跨度進一步拉開：欠繳且未受助者的畢業率為 4.454%（449 人），未欠繳而受助者為 88.63%（932 人），兩端相差 84.18 個百分點。受助者的欠繳率為 3.818%（37/969），未受助者為 16.87%（449/2,661），前者約為後者的四分之一。資助由此同時承擔兩個角色：一為收入水平的標記，二為財務壓力的緩衝。

兩項判讀界定 34.54 與 84.18 的範圍，兩數的性質限於關聯上界。第一，獎學金的制度性質（是否為須審查的資助）須以制度文件核實，核實之前它同時是收入標記與壓力緩衝，兩個角色的比重由該文件決定。第二，受助者可能本來就較有動機，或被較早識別，選拔效應因此混入上述差距。兩項合起來使「資助提高畢業率」成為與資料相容的讀法，其否證條件為：在控制入學成績與第一學期成績之後，資助的關聯若消失，則緩衝之說與資料不符。

三層的順序在合併之後確定，並決定本文的陳述方式。繳費與資助的四格跨度為 84.18 個百分點，家境四格的 phi 為 0.4349，父母職業的總效應落在顯著門檻之外。三者是同一條路徑上三個位置的量度，位置愈靠下游，跨度愈大。本文因此以上游的總效應陳述父母職業，以中游的並置模型陳述繳費與資助，並把三者分節而列；其排序與量級由同一份資料的同一母體得出。

*來源：`financial_markers.csv`、`financial_cross.csv`、`occupation_financial.csv`、`correlation_audit.csv`。*
