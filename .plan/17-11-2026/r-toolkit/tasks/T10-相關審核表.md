## Construction

- **Purpose**: 一張審核表在分析母體上重算，逐列帶判詞、校正後 p 與 `in_model`，並記錄舊版分母的來歷
- **Seam**: `programs/R/08_audit.R` — 本任務建立的入口
- **Flow it feeds**: F9（相關審核）
- **Files owned**:
  - `programs/R/08_audit.R` — 逐欄效果量、BH 校正、判詞、in_model 標記
  - `output/tables/correlation_audit.csv` — `population`、`variable`、`effect`、`p_raw`、`p_bh`、`keep`、`verdict`、`in_model`、`n`
  - `output/tables/correlation_audit.txt` — 同內容可讀版
  - `output/logs/08_audit.log` — 門檻值、分母來源、舊版分母的來歷
- **Steps**:
  1. 取分析母體；n 自 `00_setup.R` 常數與清冊取，檔內不寫字面量
  2. 逐欄計算效果量：連續欄用相關係數，類別欄用變異數分析式效果量
  3. 以 BH 法校正；門檻寫在檔內常數並印入記錄：`EFFECT_MIN = 0.30`、`P_BH_MAX = 0.05`、`EFFECT_NOISE = 0.10`
  4. 判詞四類：`definitional`（與結果同代的 `pass1`／`pass2`／`avg_grade`）、`substantive`（效果量 ≥ 0.30 且 `p_bh` < 0.05）、`noise`（效果量 < 0.10）、`ecological`（以年份為單位的三欄）
  5. `keep` 為 `definitional` 或 `substantive`；`in_model` 僅對 `substantive` 且非同代欄為 TRUE
  6. 記錄寫明舊版分母為 `RETIRED_ANALYSIS_N`（4,424，等於分析母體加在讀），磁碟上無舊表可覆蓋
- **Refusal**: `refuse:input-schema` — 分母與母體清冊不符時拒絕發佈
- **Boundaries**: 與結果同代的欄標 `definitional` 且 `in_model = FALSE`；以年份為單位的欄標 `ecological`；每列帶 population 與 n
- **Untouched**: 不動清洗資料；不改 `lib/`；不寫入母體數字字面量
