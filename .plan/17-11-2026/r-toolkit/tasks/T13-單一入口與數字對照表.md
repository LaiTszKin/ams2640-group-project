## Construction

- **Purpose**: 一條指令跑完全部步驟並產出 28 列的數字對照表，且每列帶母體與 n
- **Seam**: `programs/R/run_all.R` — 本任務建立的入口
- **Flow it feeds**: F11（交付）
- **Files owned**:
  - `programs/R/run_all.R` — 以子程序逐支呼叫各步驟、結尾檢查與產出對照表
  - `output/tables/number_map_spec.csv` — `number_key, value, source_table, source_row`；28 列，抄自報告
  - `output/tables/number_map.csv` — `number_key, spec_value, table_value, source_table, source_row, population, n, pass`
  - `output/logs/run_all.log` — 每步耗時、套件版本、執行時間、parity 判定
- **Steps**:
  1. 以子程序逐支執行，清單固定為九支且依序：`01_prep_data.R`、`02_wealth.R`、`03_age.R`、`04_ability.R`、`05_models.R`、`06_language.R`、`07_macro.R`、`08_audit.R`、`90_parity.R`（不含 `00_setup.R` 與 `run_all.R` 自身）。以 `system2(file.path(R.home("bin"), "Rscript"), c("programs/R/<name>"))` 呼叫，逐一檢查結束碼。**不得以 `source()` 呼叫**：`REQ-A-3` 的檢查式會把它計為橫向引用
  2. 結束碼 3（`refuse:parity`）記入 log 後繼續；其餘非零即停止並指出步驟
  3. 結尾依檔案與欄位對照逐表檢查母體與 n（`age_tests` 取 `population`、`n_a`、`n_b`；`marriage_strata` 取 `population`、`n`；`ability_transitions` 取 `population`、`n`），其餘九張：`wealth_four_cell`、`age_bands`、`age_tests`、`marriage_strata`、`ability_quartiles`、`ability_transitions`、`model_comparison`、`language_groups`、`macro_values`、`correlation_audit`。對照表與數字對照表本身不在此列
  4. `number_map_spec.csv` 逐列抄自報告的 28 個數字，於首次執行前寫定並置唯讀；路徑一律自 `PROJ_ROOT` 解析（不隨輸出根變動），不得由 `output/tables/` 回填。列數不等於 28 或缺任一 key 時以 `refuse:incomplete-spec` 停止。本檔為輸入，不列入「兩次執行皆產出」的檔案清單
  5. 逐列比對 spec 與表中值，產出 `number_map.csv`
  6. 記錄寫明 R 版本、套件版本、執行時間
- **Refusal**: `refuse:missing-profile`（分析表缺母體或 n，且不產出 number_map.csv）、`refuse:incomplete-spec`（spec 列數不符）
- **Boundaries**: 重跑兩次得相同的表；記錄附時間戳，表本身不附；`refuse:parity` 不中止交付流程；本入口讀 `output/tables` 的既有表屬預期行為（PRD §5 已列例外）
- **Untouched**: 不改任何分析腳本；不重寫 `lib/`；不刪除既有輸出

## Report format

完成後回報四項，缺一即視為未完成：

1. **Result** — construction：呼叫者現在看到什麼；verification A：走到哪些分支、用了多少預算、抓到什麼（trace、seed、最短序列）與**負向控制**的紅燈輸出；C：變更前後的通過與否、違規清單、門檻值與實測值（含掃描檔數）。
2. **實際建立或修改的檔案**，逐項對照 `Owned files`。
3. **偏離本檔之處與原因**；沒有則寫 `none`。
4. **在 owned files 內無法交付的部分**與其所需決定；verification 另附發現的生產缺陷與其 seam。
