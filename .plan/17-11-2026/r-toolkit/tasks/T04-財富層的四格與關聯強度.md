## Construction

- **Purpose**: 一張四格表，每格自帶人數、該格退學率與 share，並附 phi
- **Seam**: `programs/R/02_wealth.R` — 本任務建立的入口
- **Flow it feeds**: F3（財富層）
- **Files owned**:
  - `programs/R/02_wealth.R` — 四格計數、各格退學率、各格 share、phi
  - `output/tables/wealth_four_cell.csv` — `population`、`cell`、`n`、`dropout_rate`、`share`、`phi`
  - `output/logs/02_wealth.log` — 執行記錄與母體
- **Steps**:
  1. 編碼定為 `tuition_unpaid = (學費是否繳清 == 0)`、`debtor = (是否欠債 == 1)`；未指定此編碼時 phi 的符號不定
  2. 四格以固定列序輸出：兩者俱有、僅欠繳、僅欠債、皆無。此序與 report 展示的 95.13／93.08／51.87／29.32 一一對應（95.13 屬兩者俱有 226 人，不是僅欠繳的 260 人）
  3. 以**該格人數**為分母計算 `dropout_rate`；另以分析母體為分母計算 `share`（四格 share 相加為 1，容差 1e-4，因四位有效數字呈現）
  4. 以同一 2×2（欠繳=1、欠債=1）計算 phi
  5. 寫表：`population` 欄逐列填 `analysis`，`n` 欄為該格人數；不另寫首列註記
- **Refusal**: `refuse:empty-denominator` — 任一格為空時寫明空格位置並停止，且不覆寫既有表
- **Boundaries**: 四格 n 合計等於分析母體；share 四格合計為 1（容差 1e-4）；以欠債作入口的版本只在記錄留一行對照，不入表
- **Untouched**: 不寫其他分析的檔案；不改 `lib/`；不寫入母體人數的字面量（母體自 `00_setup.R` 與 `population_ledger.csv` 取）
