## Construction

- **Purpose**: 一張差異表逐格標明兩端是否一致，並在任一格超出容差時以 `refuse:parity` 結束
- **Seam**: `programs/R/90_parity.R` — 本任務建立的入口
- **Flow it feeds**: F10（兩端對照）的後半
- **Files owned**:
  - `programs/R/90_parity.R` — 讀 cell_map、母體清冊與 R 表，逐格比對；含路徑清單常數
  - `output/tables/parity_diff.csv` — `cell_id, indicator, group, r_value, sas_value, n, value_type, diff, tolerance, pass`
  - `output/logs/90_parity.log` — 整體判定、第一個不符的 cell_id、讀寫路徑清單
- **Steps**:
  1. 在檔首以兩個具名常數落路徑清單：`PARITY_READ_PATHS`（`output/parity/cell_map.csv`、`output/parity/sas_parity.csv`、`output/tables/population_ledger.csv`、`output/tables/wealth_four_cell.csv`、`output/tables/age_bands.csv`、`output/tables/ability_quartiles.csv`）與 `PARITY_WRITE_PATHS`（`output/tables/parity_diff.csv`、`output/logs/90_parity.log`）。兩者交集須為空（`REQ-A-6`）
  2. 讀母體清冊的選取器固定為 (population = `analysis`, metric = `analysis`)，取 `value` 欄；十四個 cell_id 由 `cell_map.csv` 對應到 R 表與欄
  3. 核對 `sas_parity.csv` 的 cell_id 集合**等於** `cell_map.csv` 的十四個（無重複、無未知），否則以 `refuse:input-schema` 停止
  4. 逐格比對：`count` 要求零差；`rate` 以 `diff = abs(r_value - sas_value) / abs(r_value)` 計算，`pass = diff <= PARITY_TOL`（1e-9，對未格式化 double）
  5. 以 `cell_map.csv` 的列序為固定鍵序寫表（不依 locale 字串排序），使「第一個不符」有唯一定義
  6. 結束碼：全格通過 → `quit(status = 0)`；存在不符 → 寫 log 後 `quit(status = 3)`；對照值或缺檔 → `quit(status = 1)`
- **Refusal**: `refuse:parity`（結束碼 3，不中止交付鏈）、`refuse:input-schema`（cell_id 集合不符，結束碼 1）
- **Boundaries**: 容差為計數零差、比率相對差 1e-9；本任務不寫 R 端其他表；結束碼 3 代表「已判定為不一致但流程可繼續」
- **Untouched**: 不覆寫 R 端的分析表；不改 SAS 匯出檔

1. **Result** — construction：呼叫者現在看到什麼；verification A：走到哪些分支、用了多少預算、抓到什麼（trace、seed、最短序列）與**負向控制**的紅燈輸出；C：變更前後的通過與否、違規清單、門檻值與實測值（含掃描檔數）。
2. **實際建立或修改的檔案**，逐項對照 `Owned files`。
3. **偏離本檔之處與原因**；沒有則寫 `none`。
4. **在 owned files 內無法交付的部分**與其所需決定；verification 另附發現的生產缺陷與其 seam。
