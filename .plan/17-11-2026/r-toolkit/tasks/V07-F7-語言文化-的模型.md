## Verification

- **Flow**: F7 語言文化
- **Covers**: `T08`（模型閘 `G1` 之後）
- **Shape**: `A modelling` — 判定表轉成可證偽性質，含每個拒絕分支與負向控制
- **Files owned**:
  - `tests/testthat/test-07_F7.R` — 性質與斷言
  - `tests/testthat/harness-07.R` — 本流程的預算、執行上限與入口；樣本、種子、暫存與輸出根一律取自 `helper-harness.R`
  - `tests/testthat/pins/07_F7.md` — 反例的 trace、seed、最短序列
- **Steps**:
  1. 讀已落地的 seam，逐條抄出判定表（輸入、前置、結果、拒絕類別、後置）
  2. 為每條性質寫斷言，含上列的拒絕分支；退化 fixture 一律在 `harness_dir()` 的暫存副本上造，不改 `output/`、不改 `programs/`
  3. 以測試台取得樣本、種子與暫存；執行，失敗時收縮並記下最短序列
  4. 把反例寫入 `pins/`；另指名一條被改錯的斷言做負向控制，確認測試會紅
  5. 報告附 trace、seed、收縮步數與負向控制的紅燈輸出
- **Properties（每條可證偽，含拒絕分支與負向控制）**:
  - 以全量 4,424 列（`harness_data("full")`）為樣本時，三圈 `n_members` 為 74／17／19、合計 110；分析母體上的 `n` 合計 86
  - 西語圈 `n` 11、`dropout_rate` 0.5455、`p_vs_local` 0.3586（四位有效數字後相等）
  - 西語圈區間兩端在 [0,1]、包含 0.5455，且等於以 6/11 計的威爾遜區間（相對差 1e-3）
  - `required_per_group` 以西語圈為 165±10；輸入明列 α = 0.05 雙尾、power = 0.8
  - 任一組 1 ≤ n < 10 時該列 `dropout_rate` 為 NA、其餘組照出；某圈 n = 0 時該圈列 n=0 且記錄寫明，不中止
  - 葡語圈 `p_vs_local` 為空（同語，不作跨語比較）
- **Budget**: 樣本：3,630 全列（含非本地 110、可比較 86）；無抽樣；種子 20261117（由 `helper-harness.R` 提供）；收縮上界 200 次且 30 秒；單流程上限 120 秒；重試 0 次；種子與收縮在無隨機來源的流程上記 `n/a`

## Report format

完成後回報四項，缺一即視為未完成：

1. **Result** — construction：呼叫者現在看到什麼；verification A：走到哪些分支、用了多少預算、抓到什麼（trace、seed、最短序列）與**負向控制**的紅燈輸出；C：變更前後的通過與否、違規清單、門檻值與實測值（含掃描檔數）。
2. **實際建立或修改的檔案**，逐項對照 `Owned files`。
3. **偏離本檔之處與原因**；沒有則寫 `none`。
4. **在 owned files 內無法交付的部分**與其所需決定；verification 另附發現的生產缺陷與其 seam。
